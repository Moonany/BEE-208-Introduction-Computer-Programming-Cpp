# Current Monitoring System (Question 9)

Small C++ console program for the Current Monitoring System (Question 9).

Files
- [Question_9-Current Monitoring System.cpp](Question_9-Current Monitoring System.cpp)
- [Makefile.win](Makefile.win)

Prerequisites
- A C++ compiler (g++ / clang++ / MSVC).

Build
- Build directly with `g++` (MinGW / WSL / macOS / Linux):

```powershell
g++ -std=c++17 -O2 -Wall "Question_9-Current Monitoring System.cpp" -o current_monitor.exe
```

- Or use the provided Makefile on Windows (if you have a make tool):

```powershell
make -f Makefile.win
```

Run

```powershell
.\current_monitor.exe
```
