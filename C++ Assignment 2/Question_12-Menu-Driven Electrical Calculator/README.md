# Menu-Driven Electrical Calculator

A simple C++ console application that calculates electrical values using a menu-driven interface.

## Features

- Calculate power using `P = V x I`
- Calculate resistance using `R = V / I`
- Calculate energy using `E = P x t`
- Loop until the user selects `Exit`
- Handles division-by-zero for resistance calculations

## Files

- `Question_12-Menu-Driven Electrical Calculator.cpp` - main source file
- `Makefile.win` - Windows makefile for building with `g++`
- `Psuedocode.sql` - pseudocode description of the program flow
- `Algorithm.cpp` - additional project file (source not used in README)

## Build

This project uses a Windows `Makefile` generated by Dev-C++.

1. Open a terminal in the project folder.
2. Run:

```powershell
make -f Makefile.win
```

If `make` is not available, you can compile directly with `g++`:

```powershell
g++ "Question_12-Menu-Driven Electrical Calculator.cpp" -o "Question_12-Menu-Driven Electrical Calculator.exe"
```

## Run

From the project folder, run:

```powershell
."\Question_12-Menu-Driven Electrical Calculator.exe"
```

Then choose one of the menu options and enter the requested values.

## Notes

- Enter `4` to exit the program.
- For resistance calculations, current cannot be zero.
